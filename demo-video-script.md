# TraceVault — 60-second demo video script

Target: about 145 spoken words, which is about 55 seconds at a calm pace, leaving room for the title and end cards.

| Time | On screen | Voiceover |
|---|---|---|
| 0:00–0:07 | Phone overflowing with WhatsApp chats, screenshots, voice notes. Text: *"Evidence everywhere. Case nowhere."* | "A fraud victim's evidence is scattered: WhatsApp chats, screenshots, Hindi voice notes. Most of it never makes it into the case." |
| 0:07–0:10 | TraceVault logo on the landing page | "This is TraceVault." |
| 0:10–0:19 | Upload page: drag in a folder, SHA-256 hashes appear, "Sealed" badge, Audit tab | "Drop in everything. Each file is hashed in the browser, encrypted, and logged in a tamper-evident audit chain before any AI touches it." |
| 0:19–0:28 | Viewer: OCR'd screenshot, voice note transcript (Hindi to English), highlighted phone numbers, UPI IDs, amounts | "It reads it all: OCR on screenshots, Sarvam AI on voice notes in Hindi and Hinglish, pulling out people, phone numbers, UPI IDs and amounts." |
| 0:28–0:38 | Timeline, then Graph, then the Inconsistencies list with an "edited screenshot" flag | "It links each person across sources, builds one timeline, maps who is connected to whom, and flags what doesn't add up, like an edited screenshot." |
| 0:38–0:48 | Summary with citation chips, Share dialog with expiry, Export PDF with hashes and the Section 63 BSA draft | "Every line of the summary cites its source. Share time-limited access with your lawyer or police, and export a sealed report with a draft Section 63 certificate." |
| 0:48–0:56 | Voice Statement page: recording in Hindi, then the read-aloud summary | "Victims can tell their story by voice, in their own language." |
| 0:56–1:00 | End card: TraceVault, tagline, GitHub and live links | "TraceVault. From scattered screenshots to a case that holds up." |

## Recording tips
- Run `npm run seed:demo` first so every screen already has data. Don't wait on processing during the take.
- Record each shot as its own 5–10 second clip at 1080p, then cut them to the voiceover.
- Burn in subtitles, since many judges watch without sound.
- If you run long, cut the 0:48 voice-statement shot first.
